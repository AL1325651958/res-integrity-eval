# 软件著作权申请交付清单

> 适用登记类别：计算机软件著作权登记（中国版权保护中心）　软件全称：**医院个人科研成果诚信综合评价系统 V1.0**
> 申请主体：医院（单位申请）或开发者个人——请按下述清单准备并核对材料。

## 1. 软著申请材料总览（官方要求）

依据中国版权保护中心现行登记要求（线上办理，[中国版权保护中心官网](https://www.ccopyright.com.cn)），需提交：

| # | 材料 | 要求要点 |
|---|---|---|
| 1 | 软件著作权登记申请表 | 线上填写打印，签章后上传扫描件 |
| 2 | 源程序鉴别材料 | 提交前、后各连续 30 页共 60 页；每页不少于 50 行；不足 60 页全部提交；末页应为程序结束页；**页眉标注软件全称与版本号** |
| 3 | 文档鉴别材料 | 用户手册/操作手册/设计说明书等任选其一：前、后各连续 30 页共 60 页；每页不少于 30 行；页眉标注软件全称与版本号（本包以《软件说明书》为底稿） |
| 4 | 身份证明材料 | 单位：营业执照复印件加盖公章；个人：身份证正反面 |
| 5 | 权利归属证明 | 职务开发：单位申请无需额外证明；个人申请职务开发软件需单位出具权属证明；合作/委托开发需协议 |
| 6 | 其他 | 如委托代理机构办理，附代理委托书 |

> 登记免费（官方不收费）；审查周期通常 30–60 个工作日，可选择加急（通过代理机构，产生服务费）。相关办理要点可参考：[软著申请图文教程](https://ruanzhubao.com/blogs/ruanzhu-shenqing-jiaocheng)、[计算机软件著作权申请说明](http://www.hbsea.org.cn/portal/article/index/id/166/cid/42.html)。

## 3. 源程序鉴别材料整理规范（编码阶段执行）

1. **取材范围**：前后端主要源代码文件（剔除第三方依赖、node_modules、构建产物、配置文件中的敏感信息）；
2. **页数**：前 30 页 + 后 30 页，共 60 页；若源码不足 60 页，全部提交；
3. **每页行数**：每页不少于 50 行（不足 50 行的页合并排版至 50 行以上）；
4. **页眉**：每页页眉标注"**医院个人科研成果诚信综合评价系统 V1.0**"；
5. **格式**：A4 纵向排版，建议宋体五号/小五，单倍行距；页码连续；
6. **去重**：去除重复代码块与空行堆积，保持程序连贯；
7. **末页**：最后一页应为源程序结束页（如 `}`、`</html>` 等收尾）；
8. **命名**：文件命名为"医院个人科研成果诚信综合评价系统V1.0-源程序.pdf"（或其他受理机构接受的格式）。

## 4. 文档鉴别材料整理规范（以《软件说明书》为底稿）

1. 以 `docs/软件说明书.md` 为内容底稿，排版为 A4 文档（建议生成 PDF）；
2. 前 30 页 + 后 30 页，共 60 页；每页不少于 30 行；
3. 页眉标注"**医院个人科研成果诚信综合评价系统 V1.0**"，页码连续；
4. 内容应含：软件概述、运行环境、安装/部署、功能操作说明、常见问题——现有章节已覆盖；
5. 封面建议含：软件全称、版本号、著作权人（申请主体）名称、日期。

- **单位申请（推荐）**：系统为职务开发，著作权归医院；提交营业执照副本复印件（加盖公章）；

- **权利取得方式**：原始取得；
- **开发方式**：独立开发。

## 8. 申请流程

```
1. 准备材料（本清单第 1–7 节）
2. 中国版权保护中心官网注册/登录，在线填写申请表
3. 上传申请表签章件 + 源程序 PDF + 文档 PDF + 身份证明
4. 提交受理，等待审查（30–60 个工作日，可加急）
5. 审查通过 → 领取/下载电子登记证书
6. 补正：如收到补正通知，按意见修改后重新提交（常见补正见第 9 节）
```

## 9. 常见补正问题与规避

| 补正问题 | 规避措施 |
|---|---|
| 申请表信息与鉴别材料不一致 | 软件名称/版本号全材料统一（第 5 节） |
| 源程序页数/行数不足 | 按第 3 节规范排版，每页 ≥50 行，凑足 60 页 |
| 文档行数不足 | 每页 ≥30 行；补充章节内容 |
| 页眉缺少软件名称版本 | 页眉统一标注（第 3、4 节） |
| 源程序不完整/无结尾 | 选取完整文件，末页为程序结束页 |
| 名称含禁用字样 | 避免"国家/中华/中国"等 |
