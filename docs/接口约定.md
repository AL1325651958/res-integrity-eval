# 接口约定（前后端契约）

> 版本 V1.0　本文件是前后端开发的一致契约：后端 Controller、前端 api 模块、菜单组件映射均以本文为准。
> 基础路径：`/api/v1`（前端 axios baseURL 为 `/api/v1`，后端 Context-Path 为 `/api`，Controller 前缀 `/v1/...`）

## 1. 通用约定

- 统一响应体：`{ "code": 0, "msg": "ok", "data": ... }`；`code=0` 成功，非 0 为业务错误（msg 直接展示）
- 分页请求参数：`pageNum`（默认1）、`pageSize`（默认10）；分页响应：`{ "total": n, "list": [...] }`
- 鉴权：请求头 `Authorization: Bearer <token>`；未登录返回 code=401；无权限返回 code=403
- 时间格式：`yyyy-MM-dd HH:mm:ss`；日期字段：`yyyy-MM-dd`
- 金额/分值统一为数字（后端 BigDecimal）
- 枚举/字典值使用字符串键（见字典），前端用字典接口渲染标签

## 3. 成果 achievement

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/achievement/page` | 参数：`pageNum,pageSize,status,achType,keyword,year`；本人成果（医生角色）或按数据范围 |
| POST | `/achievement` | 新增（草稿）。体：`achType,title,achNo,sourceName,publishTime,level,rankInfo,isCorresponding,fundAmount,attachIds[]` |
| PUT | `/achievement/{id}` | 编辑草稿（同新增体） |
| DELETE | `/achievement/{id}` | 删除草稿/撤销未入库成果 |
| POST | `/achievement/{id}/submit` | 提交审核（草稿→待科室初审） |
| POST | `/achievement/{id}/audit` | 审核：体 `{auditType:"APPROVE"|"BACK", opinion}`；科室初审→待科研科终审；科研科终审通过→入库并自动计分 |
| GET | `/achievement/audit/page` | 待审列表，参数：`pageNum,pageSize,status,scope`（scope=ALL 终审，DEPT 科室初审） |
| GET | `/achievement/{id}` | 详情：`{...成果, attachments:[], auditLogs:[{auditType,auditName,opinion,auditTime}]}` |
| POST | `/achievement/{id}/invalidate` | 作废（科研科），回收计分并触发重算 |
| GET | `/achievement/export` | 导出 Excel（可选） |

成果类型 `achType` 动态表单字段（与后端入库一致）：
- `PAPER`：title, sourceName(期刊), achNo(DOI), publishTime, level(分区: SCI-1区…), rankInfo, isCorresponding, attachIds(全文PDF/录用证明/检索证明)
- `TOPIC`：title, sourceName(立项部门), achNo(项目号), level(国家级/省部级/市厅级/院级), rankInfo(负责人/核心成员/参与人), fundAmount, publishTime(立项时间)
- `PATENT`：title, achNo(专利号), level(发明/实用新型/软著/外观), rankInfo(第1发明人…), publishTime(授权时间)
- `REWARD`：title, sourceName(颁奖单位), level(国家级…院级+奖次), rankInfo(第1名…), publishTime(获奖时间)
- `BOOK`：title, achNo(ISBN), level(普通/国家级规划教材), rankInfo(主编/副主编/编委)
- `STANDARD`：title, achNo(标准号), level(国际/国家/行业/地方团体/指南共识), rankInfo(主要起草人/参与起草)
- `POST`：title(任职名称), sourceName(学会名称), level(国家级/省级/市级), rankInfo(主任委员…委员)
- `TRANSFER`：title, achNo(合同号), fundAmount(到账金额), publishTime(到账时间)
