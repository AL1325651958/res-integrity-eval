# 医院个人科研成果诚信综合评价系统 软件说明书（用户操作手册）

> 软件名称：医院个人科研成果诚信综合评价系统　版本：V1.0
> 本文档同时作为软件著作权登记的文档鉴别材料底稿（排版要求见《软件著作权申请交付清单》第 4 节）

---

## 1. 软件概述

### 1.1 软件用途

医院个人科研成果诚信综合评价系统是面向医院内网的科研管理软件，实现全院医务人员科研成果的统一归集、量化评分、诚信分级、智能风险预警与全流程核查处置，评价结果直接对接职称评审、导师遴选、项目申报、评优评先等院内业务，落实科研诚信"一人一档、终身追溯"管理要求。

### 1.2 适用对象

- 普通医护人员（医师、护士、医技、科研、教学人员）
- 科室管理员
- 科研科审核员
- 科研诚信委员会
- 院领导
- 系统管理员

### 1.3 运行环境

| 项目 | 要求 |
|---|---|
| 浏览器 | Edge、Chrome、360 浏览器（兼容模式），建议 1920×1080 |
| 服务器 | 内网 Linux / Windows 服务器，JDK 17，MySQL 8.0 |
| 网络 | 医院内网 |

### 1.4 主要功能

成果填报与审核、业绩加分与诚信扣分评价、诚信等级自动判定、自动风控预警、失信核查工单、申诉复核、三级数据看板、评分规则配置、黑名单管理、日志审计、Excel 批量导入、档案 PDF 导出。

## 2. 登录与账号

1. 在浏览器地址栏输入系统地址，打开登录页面；
2. 输入**工号（登录账号）**与**初始密码**，点击"登录"；
3. 首次登录强制修改密码，密码需含字母、数字，长度不少于 8 位；
4. 连续输错密码 5 次，账号锁定 30 分钟，可联系系统管理员解锁；
5. 登录后点击右上角头像可"修改密码""退出登录"。

## 3. 个人工作台

登录后默认进入个人工作台，展示：

- 本年度科研得分、诚信等级（A/B/C/D）及等级徽标；
- 各类成果统计（论文/课题/专利/奖励数量与分值）；
- 扣分明细与整改待办；
- 风险提醒（未处理预警数）；
- 待审核成果（提交后待科室/科研科处理状态）。

## 4. 成果填报与管理

### 4.1 新增成果

1. 进入"我的成果 → 新增成果"；
2. 选择成果类型（期刊论文、课题项目、专利/软著、科技奖励、专著/教材、标准/指南、学术任职、技术转化、其他），系统按类型动态展示表单；
3. 按提示填写必填项并上传佐证附件，主要类型字段如下：

| 成果类型 | 关键字段 |
|---|---|
| 期刊论文 | 标题、期刊名称、刊期、发表时间、DOI、ISSN、影响因子、期刊分区、作者位次、是否通讯作者、全文PDF、录用证明、检索证明 |
| 课题项目 | 项目名称、立项部门、项目级别、立项/结题时间、项目经费、本人角色（负责人/核心成员/参与人）、立项书、结题证书 |
| 专利/软著 | 名称、类型（发明/实用新型/软著）、授权号、授权时间、发明人排名、证书附件 |
| 科技奖励 | 奖励名称、颁奖单位、奖励级别、获奖排名、获奖时间、证书扫描件 |
| 技术转化 | 转化方式、合同金额、实际到账金额、合同附件、到账凭证 |

4. 点击"保存草稿"可暂存，点击"提交审核"进入审核流程；
5. 附件要求：单个文件不超过 20MB，支持 PDF/JPG/PNG/DOC/DOCX/XLSX/ZIP。

### 4.2 审核流程

```
个人提交 → 科室管理员初审（核实真实性）→ 科研科审核员终审（核验编号、查重、合规性）→ 入库归档
```

- 审核不通过将退回并附修改意见，用户收到站内通知；
- 退回后可在"我的成果"中查看意见、修改后重新提交；
- 审核全程留痕，可在成果详情页查看审核流水。

### 4.3 成果管理操作

- **撤销**：入库前可撤销申报；
- **查看评分**：入库成果自动按评分规则计分，可在成果列表查看得分及计分规则；
- **重复申报提示**：同一编号（DOI/专利号/项目号）重复填报时系统预警并禁止重复计分。

## 5. 诚信档案与评分查询

### 5.1 年度评价

- 系统每年 1 月自动生成上年度评价：业绩总分 = 各项入库成果得分之和；最终得分 = 业绩总分 − 有效诚信扣分；
- 诚信等级按阈值自动判定：

| 等级 | 含义 | 判定条件 |
|---|---|---|
| A | 诚信优秀 | 无扣分、无风险、成果规范 |
| B | 诚信合格 | 轻微扣分且已完成整改 |
| C | 诚信警示 | 存在中度失信，重点监管 |
| D | 严重失信 | 严重学术不端，一票否决 |

### 5.2 查看评分明细

- 进入"诚信档案 → 年度评分"，可查看总分与**逐条明细**（每条成果的计分规则、基础分、系数、得分；每条违规的扣分与减免），确保分数可解释、可追溯；
- 支持按年度、按成果类型筛选。

### 5.3 档案导出

- 一键导出个人科研诚信档案 PDF（含成果清单、评分明细、等级结论），可直接用于职称评审、申报材料；
- 导出文件通过附件下载接口获取，仅本人及授权角色可下载。

## 6. 风险预警与申诉

### 6.1 风险预警

系统自动开展风控筛查（成果入库实时 + 每日定时），识别以下风险并生成预警：

- 一稿多投：同一 DOI/标题重复填报、短时间多篇高度相似文章；
- 署名异常：作者位次逻辑异常、多人重复排名；
- 时间逻辑：结题时间早于立项时间、发表时间与录用时间冲突；
- 黑名单期刊：命中预警期刊/出版社自动标记；
- 成果重复申报：同一课题/奖励重复填报计分。

用户在"风险提醒"中可查看自身涉事预警及说明；确有误报可提交说明材料。

### 6.2 申诉

对年度评价结果、扣分、失信认定结论有异议时：

1. 进入"诚信档案 → 我要申诉"；
2. 选择申诉对象（评价结果/扣分/认定结论），填写申诉理由并上传佐证材料；
3. 提交后由科研诚信委员会复核裁定，全程留痕；
4. 可在"我的申诉"查看处理进度与裁定结果。

## 7. 科室管理员功能

1. **成果初审**："科室审核 → 待初审"，核实真实性后点击"通过"或"退回"（必须填写意见）；
2. **科室统计**：查看本科室成果总量、各类成果分布、未审核成果；
3. **风险人员**：查看本科室风险人员清单与整改情况；
4. 科室管理员只能查看和处理**本科室**数据。

## 8. 科研科审核员功能

1. **成果终审**："成果终审"，核验编号、查重、合规性后入库，退回需填写修改意见；
2. **风险核查**："风险核查 → 工单列表"，认领待处理工单，按流程开展线上取证、调查记录录入、失信等级认定；
3. **扣分操作**：认定后生成违规记录、扣分生效、关联成果处理（作废回收计分）；
4. **整改审核**：验收 B/C 级违规整改结果，验收通过后按规则减免扣分；
5. **公示发起**：对认定结果发起公示，公示到期系统自动归档。

## 9. 科研诚信委员会功能

1. **失信最终认定**：对重大、争议认定的复核与终审；
2. **申诉复核**：受理并裁定个人申诉（维持原判/变更裁定/驳回），变更裁定自动回写扣分与等级；
3. **黑名单管理**：维护风险期刊、风险出版社、违规关键词，支持对接中科院预警名单导入；
4. **规则配置**：配置各类成果分值、违规扣分值、等级阈值（修改即新版本，不影响历史评价）。

## 10. 院领导功能

1. **全院看板**：全院科研诚信总体概况、各科室诚信排名、失信问题类型统计、年度成果趋势、严重失信人员名单、待处置工单统计（折线图/柱状图/饼图）；
2. **报表导出**：按科室、年度导出统计报表 Excel；
3. 院领导可查看全院数据，不可修改业务数据。

## 11. 系统管理员功能

1. **用户管理**：新增、启用/禁用、重置密码、绑定科室与角色；
2. **科室管理**：科室层级配置、人员归属调整；
3. **角色权限**：角色与菜单/按钮权限分配；
4. **字典管理**：成果类型、违规类型等字典维护；
5. **日志审计**：操作日志、登录日志查询（日志不可删除）；
6. **数据导入**：历史科研成果 Excel 批量导入，导入前下载模板，导入后查看校验结果报告。

## 12. 常见问题（FAQ）

| 问题 | 处理 |
|---|---|
| 忘记密码 | 联系系统管理员重置 |
| 附件上传失败 | 检查文件大小（≤20MB）与格式白名单 |
| 成果提交后无法修改 | 已进入审核流程，可联系审核人退回 |
| 对扣分有异议 | 在公示期内或收到通知后提交申诉 |
| 提示"重复申报" | 同一编号成果已存在，确认后撤销重复记录 |
| 看不到其他科室数据 | 角色数据范围限制（本人/本科室/全院） |
| 浏览器兼容 | 使用 Edge/Chrome 或 360 兼容模式 |
