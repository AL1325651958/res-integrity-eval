# 业绩评分规则（V1.0）

> 版本：V1.0（生效日期 2025-01-01）　本规则为系统初始值，全部入库（`research_rule` / `research_rule_coeff` / `research_level_config`）可配置；修改发布新版本，历史评价按快照计算，不受规则变更影响。

## 1. 计分模型

```
年度得分 = 业绩总分 − 有效诚信扣分
诚信等级  = f(有效扣分, 一票否决项, 整改情况)   # 见第 5 节
```

- **业绩总分**：该年度内入库生效的各类成果，按评价年度内有效的规则版本逐条计分求和；
- **有效诚信扣分**：认定扣分合计经整改减免后的数值；
- 同一成果（DOI / 专利号 / 项目号唯一）只计一次分，重复申报触发风险预警并扣分。

**作者位次系数**（论文通用）：

| 位次 | 系数 |

> 同一论文一人同时为第一作者与通讯作者不重复计分；通讯作者按对应位次系数 × 1.0 计。

## 11. 整改与减免

- **B 级违规**：整改完成并经科研科验收后，该条扣分 **减免 50%**，记录留存但不作为严重记录；
- **C 级违规**：整改完成并验收后，该条扣分 **减免 30%**；
- **D 级一票否决项不减免**，冻结期按认定文书执行；
- **有效扣分 = 认定扣分合计 − 减免额**，等级判定使用有效扣分。

## 12. 诚信等级自动判定（年度）

| 等级 | 名称 | 判定条件（满足任一即按最严重计） |
|---|---|---|
| A | 诚信优秀 | 年度有效扣分 = 0，且无任何风险 / 违规记录 |
| B | 诚信合格 | 0 < 年度有效扣分 ≤ 10，且所有 B 级违规已完成整改 |
| C | 诚信警示 | 10 < 年度有效扣分 ≤ 30；或存在未完成整改的 B/C 级违规 |
| D | 严重失信 | 存在任一票否决项；或年度有效扣分 > 30；或同年度 ≥ 2 项 C 级违规 |

## 13. 规则版本化与年度评价

1. 所有分值、系数、阈值存库并带 `version` + `effective_date`；发布新规则即新版本，不修改旧版本；
2. 每年 1 月定时任务生成全员年度评价：按该年度生效版本计算，结果写 `research_integrity`（汇总）+ `research_integrity_detail`（逐条明细快照，含当时规则版本）；
3. 成果作废 / 违规生效等事后变化触发**重算**，重算结果追加新快照并留审计日志；
4. 评价结果支持公示（全院/科室/个人范围），公示期内可申诉，公示结束归档。
